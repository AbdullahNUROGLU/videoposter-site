Privacy policy

Last updated: 21 November 2026

VideoPoster is a private tool used only by its owner, on the owner's own computer, for the owner's own YouTube, TikTok and Instagram accounts.

What it accesses

With the owner's permission through each platform's sign-in, VideoPoster:

  • uses the YouTube Data API and the YouTube Analytics API to upload and schedule the owner's videos, add their captions, read the owner's channel and video details, and read view and watch statistics;
  • uses the TikTok Content Posting API to send the owner's videos to the owner's own TikTok inbox as drafts;
  • uses the Instagram API to publish the owner's videos as Reels on the owner's own account and read their basic statistics.

Where the data goes

Sign-in tokens and statistics are stored only on the owner's computer. A short weekly statistics summary is sent to the owner's own private Telegram chat. User data is not sold, not shared with anyone else, not used for advertising and not used to train AI models.

Removing access

The owner can remove VideoPoster's access at any time in each platform's account settings, for Google at myaccount.google.com/permissions. Deleting the token files on the computer also ends access.

VideoPoster's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Contact the owner through the YouTube channel that uses this app.
