Privacy policy

Last updated: 21 November 2026

VideoPoster is a private tool used only by its owner, on the owner's own computer, for the owner's own YouTube channels.

What it accesses

With the owner's permission through Google sign-in, VideoPoster uses the YouTube Data API and the YouTube Analytics API to:

  • upload and schedule the owner's videos, and add their captions;
  • read the owner's channel and video details;
  • read view and watch statistics for the owner's channels.

Where the data goes

The sign-in token and the statistics are stored only on the owner's computer. A short weekly statistics summary is sent to the owner's own private Telegram chat. Google user data is not sold, not shared with anyone else, not used for advertising and not used to train AI models.

Removing access

The owner can remove VideoPoster's access at any time at myaccount.google.com/permissions. Deleting the token file on the computer also ends access.

VideoPoster's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Contact the owner through the YouTube channel that uses this app.
